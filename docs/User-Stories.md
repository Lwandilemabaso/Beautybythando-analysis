# User Stories

## US-001

As a client,

I want to view available services,

So that I can choose the service I require.

---

## US-002

As a client,

I want to book an appointment online,

So that I can reserve my preferred timeslot.

---

## US-003

As a client,

I want booking confirmation,

So that I know my appointment has been scheduled.

---

## US-004

As a makeup artist,

I want to manage bookings,

So that I can avoid scheduling conflicts.

---

## US-005

As a makeup artist,

I want to generate reports,

So that I can monitor business performance.
