# Functional Requirements

## FR-001

The system shall allow clients to view services.

## FR-002

The system shall allow clients to view available slots.

## FR-003

The system shall allow clients to book appointments.

## FR-004

The system shall allow clients to cancel appointments.

## FR-005

The system shall send booking confirmations.

## FR-006

The system shall allow administrators to manage bookings.

---

# Non-Functional Requirements

## Performance

Pages should load within 3 seconds.

## Security

Only authenticated administrators may access the dashboard.

## Availability

The system should be available 24/7.

## Reliability

Double-bookings must be prevented.
